Private Beta Submit an annual statement

User group: Supervising engineers

Sprint 0

Download and upload statement

Tested Version 8
Design iterations

Changed the service from being all questions filled out online, to the user being able to download a Word template to fill out offline.

  • New design: Start page – Added new content that explained what the service does
  • Sign in – Enter email address and password
  • Choose a reservoir – Search for a reservoir statement by autocomplete
  • New design: Download an annual statement template for [Named Reservoir] – users could download a template for the reservoir selected, also gave option to download an additional template
  • New design: Template downloaded – confirmation page showing user the statement has been downloaded. What's next section explaining the process and a link back to view their account
  • New design: Your annual statements – list of all the reservoirs in your account
  • New design: Upload an annual statement template for [Named Reservoir] – users could download a template for the reservoir selected
  • New design: Annual statement sent – confirmation page showing user the statement has been sent. What's next section allowing the user to return to send a nother annual statement or view their account

What we tested

To evaluate our prototype concept for submitting the section 12 statements online.

  • What do engineers think of the proposed process?
  • What benefits do they see? Why?
  • What challenges might occur? Why?
  • What might improve this approach? Why?
  • What requirements do they have for a template?
  • What should it do? Why?
  • What should be avoided? Why?
  • What, if any, additional information would they want to highlight to the EA when submitting?

To evaluate and prioritise some additional features that might be included in the service.

  • What benefits would occur from having these features?
  • How would they rank/prioritise the features?
  • Which of the features would encourage them to use the service?

Sprint 3

Download and upload statement

Tested Version 9
Design iterations
  • Download an annual statement template for [Named Reservoir] – replaced 'National Grid reference' with 'Nearest town'
  • New design: Your annual statements – to allow the user to see current and previous statements. In the table added 'Town' and an action button for 'Upload'
  • Annual statement sent – confirmation page showing user the statement has been sent. What's next section allowing the user to return to send another annual statement or view their account
Tested Version 9.1
Design iterations

Removed the Search for a reservor page and incorporated this fuctionality into the Your annual statements page. Changed the order of Download an annual statement template for [Named Reservoir] page

  • New design: Your annual statements – user can now search download and uplaod a reservoir statement. New status tags usedd to show if something is 'Not started', 'In progress' or 'Sent'
  • New design: Send the annual statement to the undertaker – showing the undertakers name and contact details. User can then choose to send a copy of the statement directly through the service

What we tested

To usability test the upload/download process for the template

  • Are they able to complete the tasks (upload/download)?
  • What challenges do they face when using the service?
  • What concerns do they have about using the service?
  • Which of the design options do they prefer & why?
