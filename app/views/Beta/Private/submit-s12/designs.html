Sprint 0

Download and upload statement

Tested Version 8
Design iterations

Changed the service from being all questions filled out online, to the user being able to download a Word template to fill out offline

  • New design:

    Start page

    Add new content to explain what the service does

  • Sign in

    Enter username and password

  • Choose a reservoir

    Search for a reservoir statement by autocomplete

  • New design:

    Download an annual statement template for [Named Reservoir]

    User can download a template for the reservoir selected, also has option to download an additional template

  • New design:

    Template downloaded

    Confirmation page shows the user the statement has been downloaded. What's next section explaining the process and a link back to view their account

  • New design:

    Your annual statements

    List of all the reservoirs in the user account

  • New design:

    Upload an annual statement template for [Named Reservoir]

    User can download a template for the reservoir selected

  • New design:

    Annual statement sent

    Page shows the user the statement has been sent. What's next section allowing the user to return to send another statement or view their account

What we tested

To evaluate our prototype concept for submitting the section 12 statements online

  • What do engineers think of the proposed process?
  • What benefits do they see? Why?
  • What challenges might occur? Why?
  • What might improve this approach? Why?
  • What requirements do they have for a template?
  • What should it do? Why?
  • What should be avoided? Why?
  • What, if any, additional information would they want to highlight to the EA when submitting?

To evaluate and prioritise some additional features that might be included in the service

  • What benefits would occur from having these features?
  • How would they rank/prioritise the features?
  • Which of the features would encourage them to use the service?
